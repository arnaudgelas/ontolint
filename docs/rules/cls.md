#### CLS001: Disconnected class

- **Severity:** info
- **Scope:** term
- **Category:** heuristic
- **Fix:** Inspect whether the class is intentional: it has no sub/superclass or equivalence link, is not deprecated and is never used as a domain, range, restriction filler or type.
