### Module lexical

#### LEX001: Term without label

- **Severity:** warning
- **Scope:** term
- **Category:** heuristic
- **Module:** [`lexical`](#module-lexical)
- **Fix:** Add rdfs:label or an accepted alternative to the declared local term.

**Specification.** An owned term with no ``Literal`` value under a label predicate; a blank label counts (LEX005 reports it) and a non-literal label does not (LEX013 reports it).  Excluded: a term with ``owl:deprecated true`` (METRIC001 counts the same terms).  Confidence ``certain``, but ``heuristic`` when the term has a literal under a predicate whose local name contains ``label``, ``name`` or ``title`` that is not a label predicate (``ex:hasName``).  Warning: RDFS 5.4.1 makes a label optional, so this is a documentation convention.

*Flagged:* `no label`

```turtle
ex:A a owl:Class .
```

Reported: `Term has no label.`

*Flagged:* `a sub-property of rdfs:comment`

```turtle
ex:c rdfs:subPropertyOf rdfs:comment . ex:A a owl:Class ; ex:c "A" .
```

Reported: `Term has no label.`

*Flagged:* `a sub-property of skos:altLabel`

```turtle
skos:altLabel rdfs:subPropertyOf rdfs:label . ex:alt rdfs:subPropertyOf skos:altLabel . ex:A a owl:Class ; ex:alt "A" .
```

Reported: `Term has no label.`

*Clean:* `rdfs:label`

```turtle
ex:A a owl:Class ; rdfs:label "A" .
```

*Clean:* `deprecated terms are exempt`

```turtle
ex:A a owl:Class ; owl:deprecated true .
```

*Clean:* `label through a chain of sub-properties`

```turtle
ex:l2 rdfs:subPropertyOf ex:l1 . ex:l1 rdfs:subPropertyOf skos:prefLabel . ex:A a owl:Class ; ex:l2 "A" .
```

*Clean:* `label through an equivalent`

```turtle
ex:name owl:equivalentProperty rdfs:label . ex:A a owl:Class ; ex:name "A" .
```

#### LEX003: Multiple labels in one language

- **Severity:** warning
- **Scope:** term
- **Category:** heuristic
- **Module:** [`lexical`](#module-lexical)
- **Fix:** Use one language-specific primary label per term and language.

**Specification.** Per owned term, a language with more than one distinct literal in the *preferred family*: ``skos:prefLabel`` and below, or when the term has none, its main labels.  Two literals are one when their text, datatype and lower-cased language are equal, so ``"A"`` and ``"A"^^xsd:string`` count once (RDF 1.1 Concepts 3.3). SKOS Reference 5.4 S14: "A resource has no more than one value of skos:prefLabel per language tag".  Excluded: an ``rdfs:label`` beside a ``skos:prefLabel`` (a notation or a specialised label), a sub-property of ``rdfs:label`` beside a main label.  Warning: in SKOS the term is then inconsistent (S14 is an integrity condition); outside SKOS it is a convention.

*Flagged:* `two labels in one language`

```turtle
ex:A a owl:Class ; rdfs:label "A"@en, "Aye"@en .
```

Reported: `2 labels for language en.`

*Clean:* `one label per language`

```turtle
ex:A a owl:Class ; rdfs:label "A"@en, "A"@fr .
```

*Clean:* `prefLabel and rdfs:label`

```turtle
ex:A a owl:Class ; skos:prefLabel "A"@en ; rdfs:label "1 A"@en .
```

*Clean:* `a specialised label beside rdfs:label`

```turtle
ex:short rdfs:subPropertyOf rdfs:label . ex:A a owl:Class ; rdfs:label "Aye"@en ; ex:short "A"@en .
```

- **Scope:** term
- **Category:** heuristic
- **Module:** [`lexical_quality`](#module-lexical_quality)

**Specification.** A value of a label predicate that is not a literal, or of a definition predicate that is neither a literal nor a node with ``rdf:value`` (the SKOS documentation-note pattern, SKOS Reference 7.1 and 7.3). *Flagged:* `IRI label`


*Flagged:* `blank-node definition`

```turtle

```

Reported: `http://www.w3.org/2004/02/skos/core#definition value is not a literal.`

#### LEX015: Alternative label repeats the preferred label

- **Severity:** info
- **Scope:** term
- **Category:** heuristic
- **Module:** [`lexical_quality`](#module-lexical_quality)
- **Fix:** Remove alternative labels that equal the term's own label in the same language.

**Specification.** An alternative label (``skos:altLabel``, ``skos:hiddenLabel``) whose normalised text and language equal a main label of the same term.  SKOS Reference 5.4 S13: the three label properties are pairwise disjoint; the rule is wider (case and inner whitespace ignored) and does not report an ``skos:altLabel`` that equals a ``skos:hiddenLabel`` (decided in issue #155: SKOS002 reports the exact overlap, and no rule reports a case or whitespace variant, which the 21-file calibration corpus does not contain).  Info.

*Flagged:* `altLabel equals prefLabel`

```turtle

```

Reported: `Alternative label 'car' repeats the term's own label.`

*Clean:* `different text`

```turtle
ex:A a owl:Class ; skos:prefLabel "Car" ; skos:altLabel "Auto" .
```

*Clean:* `other language`

```turtle
ex:A a owl:Class ; skos:prefLabel "Car"@en ; skos:altLabel "Car"@fr .
```

#### LEX018: Label contains markup or character entities

- **Severity:** warning
- **Scope:** term
- **Category:** heuristic
- **Module:** [`iri_lexical_extras`](#module-iri_lexical_extras)
- **Fix:** Store labels as plain text; remove HTML/XML tags and character entities.

**Specification.** A label of an owned term (``rdfs:label``, ``skos:prefLabel``, ``skos:altLabel`` and any configured extra label predicate) containing an XML/HTML tag (``<b>``, ``</b>``) or a named, decimal or hexadecimal character entity (``&amp;``, ``&#233;``).  A bare ``<``, ``>`` or ``&`` is plain text, and a trailing ``<word>`` disambiguator that is not an HTML tag name is allowed.  Comments and definitions are not labels and are not checked, nor is ``skos:hiddenLabel``.  The tag list is the HTML tags of ``HTML_TAGS``; ``<foo>`` alone is text.  Confidence ``heuristic``.  Warning: RDFS 5.4.1 and SKOS 5.3 give the label a plain literal, where markup shows as characters (an ``rdf:HTML`` literal would be the way to carry it).

*Flagged:* `html tag`

```turtle
ex:A a owl:Class ; rdfs:label "<b>Thing</b>" .
```

Reported: `Label '<b>Thing</b>' contains markup or a character entity.`

*Flagged:* `entity`

```turtle
ex:A a owl:Class ; skos:prefLabel "R&amp;D" .
```

Reported: `Label 'R&amp;D' contains markup or a character entity.`

*Flagged:* `alt label numeric entity`

```turtle
ex:A a owl:Class ; skos:altLabel "a&#233;b" .
```

Reported: `Label 'a&#233;b' contains markup or a character entity.`

*Flagged:* `sub-property of rdfs:label`

```turtle
ex:l rdfs:subPropertyOf rdfs:label . ex:A a owl:Class ; ex:l "<i>A</i>"@en .
```

Reported: `Label '<i>A</i>' contains markup or a character entity.`

*Clean:* `plain`

```turtle
ex:A a owl:Class ; rdfs:label "R&D" .
```

*Clean:* `sub-property of rdfs:comment`

```turtle
ex:c rdfs:subPropertyOf rdfs:comment . ex:A a owl:Class ; ex:c "<i>A</i>" .
```

*Clean:* `comparison signs`

```turtle
ex:A a owl:Class ; rdfs:label "a < b > c" .
```

*Clean:* `disambiguator in angle brackets`

```turtle
ex:A a owl:Class ; rdfs:label "Gnathostomata <vertebrates>" .
```

*Clean:* `comment is ignored`

```turtle
ex:A a owl:Class ; rdfs:comment "<b>x</b>" .
```

#### LEX025: Whitespace-padded annotation value

- **Severity:** warning
- **Scope:** term
- **Category:** heuristic
- **Module:** [`annotation_whitespace`](#module-annotation_whitespace)
- **Fix:** Trim the leading and trailing whitespace of the annotation value.

**Specification.** A string literal (plain, language-tagged or ``xsd:string``) whose lexical form starts or ends with whitespace (anything ``str.strip()`` removes, a no-break space included), used as the object of an annotation property on an owned IRI subject.  An annotation property is one declared ``owl:AnnotationProperty`` in the graph, a documentation predicate (``rdfs:comment``, ``skos:definition``, ``dcterms:description``, ``obo:IAO_0000115`` and the other definition predicates, plus any configured extra definition predicate and the predicates below them), a SKOS note or ``skos:altLabel`` / ``skos:hiddenLabel``, ``dcterms:title``, ``dc:title`` or an ``oboInOwl`` synonym.  The label predicates (``rdfs:label``, ``skos:prefLabel``, the configured extra label predicates and everything below them) are left to LEX005, so a label is never reported twice, and a blank value of a definition predicate is left to LEX019.  One finding per property and literal on a subject, so the same padded text under two properties is two findings.  Excluded: a subject that is a blank node or not owned, a non-string datatype and an annotation under an undeclared custom predicate (known gap: no declaration, no finding).  ``skos:hiddenLabel`` and ``skos:altLabel`` are judged here, since they are no label of LEX005.  Confidence ``certain``.  Warning: RDF 1.1 Concepts 3.3 compares lexical forms character by character, so a padded value is a different literal from the trimmed one and every consumer that matches on text sees two values.

*Flagged:* `trailing space in a comment`

```turtle
ex:A a owl:Class ; rdfs:comment "A thing. "@en .
```

Reported: `http://www.w3.org/2000/01/rdf-schema#comment value 'A thing. ' has leading or trailing whitespace.`

*Flagged:* `leading tab in a definition`

```turtle
ex:A a owl:Class ; skos:definition "\tA thing." .
```

Reported: `http://www.w3.org/2004/02/skos/core#definition value '\tA thing.' has leading or trailing whitespace.`

*Flagged:* `padded synonym`

```turtle
ex:A a owl:Class ; skos:altLabel " other"@en .
```

Reported: `http://www.w3.org/2004/02/skos/core#altLabel value ' other' has leading or trailing whitespace.`

*Flagged:* `padded value of a declared annotation property`

```turtle
ex:note a owl:AnnotationProperty . ex:A ex:note "x " .
```

Reported: `https://example.test/onto#note value 'x ' has leading or trailing whitespace.`

*Clean:* `trimmed comment`

```turtle

```

*Clean:* `padded label is LEX005`

```turtle
ex:A a owl:Class ; rdfs:label "A " .
```

*Clean:* `blank definition is LEX019`

```turtle
ex:A a owl:Class ; rdfs:label "A" ; rdfs:comment "  " .
```
